# Verification evidence

This directory contains machine-readable evidence for the exact repository
tree. Status dimensions are independent:

- `LOCAL_GREEN`: format, vet, unit, application, contract and architecture;
- `DB_GREEN`: live PostgreSQL migrations, concurrency and failover;
- `PROVIDER_GREEN`: real Git, registry, secret and capability providers;
- `K8S_GREEN`: real runtime cell and network/storage isolation;
- `SECURITY_GREEN`: identity, secret sentinel and offensive suites;
- `OPS_GREEN`: backup/restore, chaos, reconciliation and observability.

`status.yaml` must never infer a live status from compile-only, fake-only or
rendered-manifest evidence. `tdd-matrix.json` is generated by
`scripts/generate-pivot-tdd-matrix.py`.
